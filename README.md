# Игра-платформер "Спасение кота"

Небольшой браузерный платформер на чистом HTML/CSS/JavaScript с использованием Canvas.

## Управление
- Стрелки влево/вправо или A/D - движение.
- Space (Пробел) или W - прыжок.
- На телефоне - экранные кнопки 
- Кнопки интерфейса - Старт, Пауза, Заново.

## Как запустить
Так как игра использует ES-модули, открывать `index.html` двойным кликом (через `file://`) нельзя - браузер заблокирует скрипты. Запуск производится через локальный сервер:
1. Откройте терминал в папке с проектом.
2. Выполните `python -m http.server 8000` (или используйте расширение Live Server в VS Code).
3. Перейдите по адресу `http://localhost:8000`.

## О работе с нейросетью
При создании проекта использовалась нейросеть для генерации кода (игровой цикл, физика столкновений, отрисовка Canvas).
Примеры промптов:
1. "Создай платформер на HTML/CSS/ванильном JS с Canvas. Нужны ES-модули... Выдай каждый файл полностью."
2. "Добавь Player: движение стрелками/A-D, прыжок Space/W, гравитацию. Прыжок доступен только с опоры."
3. "В игре проблема: прыжок не достает до последней рыбки, после поражения не нажимается кнопка Заново. Исправь."

## Использованные ресурсы (изображения/звук)
Внешние изображения и звуковые файлы не используются. Вся графика (персонаж, кот, рыбки, фон, платформы) нарисована программно с помощью Canvas API.
